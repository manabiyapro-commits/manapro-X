# 教採・臨採 季節カレンダー（読者ニーズの目安）

投稿のテーマ選びに使う、一般的な年間の流れです。日程や制度は自治体・年度によって異なります。
**具体的な日付や制度を投稿に書くときは、必ずその自治体の最新の実施要項や公式サイトで確認してください。**
内容は、毎週の投稿案づくりの前に調べ直して更新します。

| 時期 | 受験生の状況 | 読者が知りたいこと（投稿テーマの候補） |
|---|---|---|
| 9〜10月 | 最終合格の発表。来年に向けて動き出す | 不合格からの立て直し、来年への逆算計画、教職教養の始め方 |
| 10〜12月 | 来夏の受験に向けた基礎固め。臨採（講師）として働きながら受験する人も多い | 勉強の習慣づくり、働きながらの勉強時間の確保、講師登録の考え方 |
| 1〜3月 | 実施要項の発表が始まる自治体も。次年度の講師任用の連絡が来る時期 | 志望自治体の選び方、過去問の使い方、講師の任用の流れ |
| 4〜5月 | 願書の提出。新年度の講師勤務が始まる | 願書・自己PRの書き方、教育時事、仕事と勉強の両立 |
| 6〜7月 | 1次試験（多くの自治体）。直前期 | 直前期の過ごし方、当日の注意点、面接対策 |
| 8〜9月 | 2次試験（面接・模擬授業など） | 面接・模擬授業・場面指導の対策 |
