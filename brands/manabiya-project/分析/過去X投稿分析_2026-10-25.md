## データの範囲と限界
- 対象: Buffer API から取得した、Xの投稿済みの投稿 116件（2025-10-08〜2026-10-10）。データは `分析/過去投稿.csv` にあります。
  - Buffer から投稿したもの（69件）と、Xで直接投稿したもの（47件）の両方を含みます。
- 取得できた指標: 表示回数、いいね（Buffer上の reactions）、リポスト、返信、クリック、エンゲージメント率（Bufferが計算した値）。
- **取得できなかった指標（推測で補っていません）**: ブックマーク、プロフィールへのアクセス、フォロワー数の推移、リンク先ごとのクリック、**noteの販売数・売上**。
- 注意点:
  - クリックは、Bufferの「Clicks」の値です。Bufferの説明では「投稿内のリンクのクリック数」です。
  - リンクは t.co の短縮URLで、行き先はこの環境からは確認できません。どのnote記事へのリンクかは、本文から判断しています。
  - 指標の更新日は投稿によって違います（古い投稿は、投稿の数週間後で値が止まっています）。
  - 表示回数が0の投稿が4件あります（同じ内容の重複投稿など）。集計からは除いています。

## 違いの整理
1. **表示やいいねが多いことと、販売につながることは別です。** 意見・時事へのコメントは、いいねの平均が最も高い（5.1）一方で、クリックはほぼありませんでした。届いている人が、教材を探している受験生とは限らないためと考えられます。
2. **具体的な体験や、教材の中身がわかる告知はクリックされやすい傾向です。**「実際に聞かれた質問」「もし不合格だったら」「教育基本法の予想問題集」など、誰向けで何が得られるかがはっきりした投稿が上位でした。
3. **あいまいな予告や、強い言葉の告知はクリックされにくい傾向です。**「革命」「すごいもの」「絶対に参考になる」といった投稿は、具体的な告知よりクリック率が低くなっています。
4. **同じ文のくり返しは逆効果です。** 定型文の毎日問題は68件あってクリックが0件で、表示回数も3分の1程度まで減りました。
5. **時期の空白**: 2026年2月〜6月中旬は投稿がありません。来夏の受験に向けて勉強を始める大事な時期です。
6. **時間帯**（定型文の投稿を除く）: 18〜20時台の表示回数の中央値は192、21〜23時台は122。ただし件数が少ないので、目安にとどめてください。

## 売上につなげるための改善案
- **無料で役立つ情報 → 2日後に有料記事の紹介**、という流れで投稿する（同じテーマで2〜3本をつなげる）。
- 紹介の投稿には、「誰向けか・何が得られるか・価格・特典」を具体的に書く。向いていない人も正直に書く。
- 定型文の毎日問題はやめ、1問ごとに本文と切り口を変える。
- 意見・時事へのコメントは、フォロワーを増やすためと割り切り、多くても週1本にする（売上の施策とは分けて考える）。
- 投稿は、2〜6月を含めて年間を通じて続ける（受験の準備期間に空白をつくらない）。
- **効果を確かめるために**、noteの記事ごとの販売数を週1回、`note売上.csv` に記録する。Xの紹介投稿の日付と照らし合わせて、売上につながったかを確認する（クリックと購入を1件ずつ結びつけることはできないため、週単位で比べる）。
