# manapro-X

まなび舎（や）プロジェクトの X（@manabiyapro）投稿を半自動で運用するリポジトリです。
投稿案の作成 → 人による承認 → Buffer への予約登録、までを扱います。

もとは `manapro-site` リポジトリの `claude/note-writing-system` ブランチ（未マージ）の `x-posting/` で運用していたものを、
変更履歴ごとこのリポジトリの直下に移しました。note 記事の取得・執筆の仕組みは移していません。

## 中身

| パス | 役割 |
|---|---|
| `CLAUDE.md` | 運用のルールと、Claude 向けの毎週の流れ |
| `tools/x_tool.py` | 投稿案のチェック・承認・Buffer への登録・分析を行うツール |
| `brands/manabiya-project/` | 週次の投稿案、投稿履歴、登録記録、分析、紹介する有料 note 記事のリスト |
| `週次自動作成.md` | 日曜の朝に翌週の投稿案14本を作る手順（登録はしない） |
| `週次追加登録.md` | 水曜・木曜 20:45 に、予約枠の空きへ承認済みの投稿を登録する手順 |
| `tests/test_push_mock.py` | 模擬サーバーを使った登録処理のテスト |

## 毎週の流れ

1. 日曜の朝：翌週の投稿案14本を作る（`週次自動作成.md`）。
2. ユーザーがチャットで投稿IDを指定して承認 → 承認済みの投稿だけを Buffer に登録（`CLAUDE.md`）。
3. 水曜・木曜の夜：入りきらなかった承認済みの投稿を、空いた枠に登録（`週次追加登録.md`）。

運用中の記録（週次ファイル・登録記録・投稿履歴・分析）は `main` に直接コミットします。
ツールや手順書を変えるときは、作業用ブランチからプルリクエストを出し、もう一人が確認してからマージします。

## 必要な設定

- 環境変数 `BUFFER_API_KEY`（Buffer の API キー）。リポジトリには書きません。
- Python 3（標準ライブラリのみ）

## 動作確認

```
python3 tests/test_push_mock.py
python3 tools/x_tool.py validate --brand manabiya-project 週次/2026-W45.md
```
